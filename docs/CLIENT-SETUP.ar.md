# تسليم BookFlow لزبون جديد (نسخة خاصة لمحل واحد)

كل زبون بياخذ نسخة لحاله: داتابيس خاصة فيه، وسيرفر، وموقع باسمه.
نفس الكود (هاد الريبو) بيشتغل للكل، والفرق بس بإعدادات (Environment Variables).

> الوقت المتوقع: 30–45 دقيقة للزبون الواحد.

---

## 1. اطلب من الزبون

| الشي | مثال | ملاحظة |
|---|---|---|
| اسم المحل | صالون الورد | بيطلع فوق الموقع وباسم التاب |
| رابط قصير بالإنجليزي (slug) | `al-ward` | حروف صغيرة وأرقام وشرطات بس |
| إيميل وكلمة سر المالك | owner@alward.ps | كلمة السر 8 أحرف على الأقل |
| الخدمات | قص شعر - 40₪ - 30 دقيقة | الاسم، السعر، المدة |
| الموظفين | سارة، أحمد | لكل واحد إيميل وكلمة سر |
| ساعات العمل | السبت-الخميس 9:00-17:00 | الافتراضي: السبت-الخميس 9-5، الجمعة مسكّر |
| دومين (اختياري) | alward.ps | إذا ما في، بيشتغل على رابط Vercel |

---

## 2. الداتابيس (MongoDB Atlas)

1. ادخل على [cloud.mongodb.com](https://cloud.mongodb.com)، واستخدم نفس الـ cluster (المجاني M0 بيكفي لكذا زبون صغير).
2. **Network Access** ← `0.0.0.0/0` (إذا مش مضاف).
3. خذ رابط الاتصال، وغيّر اسم الداتابيس بآخره لاسم الزبون:
   ```
   mongodb+srv://USER:PASS@cluster0.xxxxx.mongodb.net/al-ward
   ```
   كل زبون = داتابيس منفصلة (`/al-ward`، `/clinic-x`...)، فبياناتهم ما بتختلط.

---

## 3. السيرفر (Render)

1. **New** ← **Web Service** ← اختار ريبو BookFlow.
2. الإعدادات:
   - **Name:** `al-ward-api`
   - **Root Directory:** `server`
   - **Build Command:** `npm ci`
   - **Start Command:** `npm start`
3. **Environment Variables:**

   | Key | Value |
   |---|---|
   | `NODE_ENV` | `production` |
   | `MONGO_URI` | رابط الداتابيس من الخطوة 2 |
   | `JWT_SECRET` | اضغط **Generate** |
   | `JWT_EXPIRES_IN` | `7d` |
   | `SINGLE_BUSINESS_SLUG` | `al-ward` |

4. انسخ رابط السيرفر، مثلًا `https://al-ward-api.onrender.com`.

> ⚠️ الخطة المجانية بتنام بعد 15 دقيقة، وأول زبون بيستنى ~50 ثانية. لمحل حقيقي انصح الزبون بخطة **Starter** (حوالي 7$ بالشهر، بيدفعها هو).

---

## 4. أنشئ المحل وحساب المالك

من جهازك، بمجلد `server`، بالـ PowerShell:

```powershell
$env:MONGO_URI="mongodb+srv://USER:PASS@cluster0.xxxxx.mongodb.net/al-ward"
$env:OWNER_PASSWORD="كلمة-سر-المالك"
npm run create-business -- --name "صالون الورد" --slug al-ward --owner "أحمد" --email owner@alward.ps --phone 0599123456
```

السكربت بيطبعلك الإعدادات اللي بتحتاجها بالخطوة الجاية.
إذا الـ slug أو الإيميل موجودين من قبل، بيوقف بدون ما يغيّر إشي.

---

## 5. الموقع (Vercel)

1. **Add New** ← **Project** ← نفس ريبو BookFlow.
2. **Root Directory:** `client`
3. **Environment Variables:**

   | Key | Value |
   |---|---|
   | `API_URL` | رابط Render من الخطوة 3 (بدون `/api`) |
   | `NEXT_PUBLIC_BUSINESS_SLUG` | `al-ward` |
   | `NEXT_PUBLIC_BRAND_NAME` | `صالون الورد` |
   | `NEXT_PUBLIC_DEMO_MODE` | `false` |
   | `NEXT_PUBLIC_CURRENCY` | `₪` (أو `$`، `JD`...) |

4. **Deploy**.

النتيجة: الصفحة الرئيسية بتفتح على صفحة حجز المحل مباشرة، وما في قائمة محلات ولا تسجيل محلات جديدة.

---

## 6. جهّز المحل

ادخل بحساب المالك ← **لوحة التحكم**:
1. **الخدمات** ← أضف كل خدمة (الاسم، السعر، المدة).
2. **الموظفون** ← أضف الموظفين.
3. **ساعات العمل** ← عدّلها واحفظ.

---

## 7. افحص قبل التسليم ✅

- [ ] افتح الموقع من الجوال: بيفتح على صفحة الحجز باسم المحل.
- [ ] احجز كضيف (اسم + رقم) ← بيطلع "رابط حجزك" (لمشاهدة الحجز أو إلغائه).
- [ ] افتح رابط إدارة الحجز وجرّب الإلغاء.
- [ ] ادخل كمالك ← الموعد ظاهر بالجدول ← جرّب **تأكيد** و**تذكير واتساب**.
- [ ] جرّب تبديل اللغة عربي/إنجليزي.
- [ ] احذف الحجوزات التجريبية (ألغيها) قبل التسليم.

---

## 8. دومين خاص (اختياري)

Vercel ← المشروع ← **Settings** ← **Domains** ← أضف الدومين واتبع تعليمات الـ DNS.

## 9. ألوان خاصة بالزبون (اختياري)

الألوان كلها بملف `client/src/app/globals.css` (أول سطور `--color-...`).
بما إنه كل الزبائن بيشتغلوا من نفس الكود، اعمل فرع خاص للزبون (`client/al-ward`)،
غيّر الألوان فيه، وبـ Vercel ← **Settings** ← **Git** خلّي **Production Branch** هو هالفرع.

---

## ملاحظات مهمة

- **التحديثات:** أي شي بتدمجه على `main` بينزل تلقائيًا عند كل الزبائن اللي مشاريعهم على `main`. عشان هيك `main` محمي والاختبارات لازم تنجح قبل الدمج.
- **النسخ الاحتياطي:** Atlas المجاني ما فيه نسخ احتياطي تلقائي. لزبون مهم، صدّر الداتابيس كل فترة أو استخدم خطة مدفوعة.
- **كلمات السر:** لا تبعتها بالشات مع الإعدادات. خلّي المالك يغيّرها أول ما يستلم.
